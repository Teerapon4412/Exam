# เตรียมย้าย Factory Exam ไป Windows ภายในโรงงาน

สถานะ: เอกสารเตรียมการเท่านั้น ยังไม่ได้ย้ายหรือสำรองข้อมูลจริงจาก Render

## 1. ข้อมูลที่ต้องรวบรวม

- ผู้รับผิดชอบ IT และผู้อนุมัติวันย้าย
- รุ่น Windows, RAM, พื้นที่ SSD, จำนวนผู้ใช้พร้อมกัน
- IP คงที่, ชื่อภายในที่ต้องการ, พอร์ต (ค่าเริ่มต้น 3000)
- การเข้าถึงระหว่าง LAN และ Wi-Fi รวมทั้ง Firewall
- ที่เก็บสำรองแยกเครื่อง และระยะเวลาเก็บข้อมูล
- Node.js รุ่นที่รองรับ better-sqlite3 ใน package-lock.json
- AUTH_SECRET เดิม: เก็บในช่องทางลับ ห้ามส่งเข้า Git หรือแนบในคู่มือ

## 2. ข้อมูลจริงที่ต้องนำจาก Render

- factory-exam.sqlite: มีพนักงาน สิทธิ์ คลังข้อสอบ ผลสอบ เกณฑ์และผลประเมิน
- ไฟล์รูปหรือไฟล์แนบที่เก็บแยกจากฐานข้อมูล (ถ้ามี)
- รายการรูปภายนอก ฟอนต์ และทรัพยากรที่ยังต้องใช้อินเทอร์เน็ต
- ค่าตั้ง DATA_DIR, PORT และ AUTH_SECRET โดยไม่เผยแพร่ค่าลับ

โค้ด GitHub ไม่ใช่ฐานข้อมูลจริงของ Render ห้ามแทนข้อมูลจริงด้วยข้อมูลเริ่มต้น
สำรองด้วย SQLite backup API หรือหยุดระบบก่อนคัดลอก ห้ามคัดลอกเฉพาะไฟล์ .sqlite
ขณะที่ระบบกำลังเขียน เพราะอาจมีข้อมูลค้างในไฟล์ -wal

## 3. สำรอง SQLite อย่างสอดคล้องกัน

หลังติดตั้ง dependencies แล้ว ใช้เครื่องมือจากรากโปรเจกต์:

    node migration/windows/backup.cjs "เส้นทางฐานข้อมูลต้นฉบับ" "โฟลเดอร์ปลายทางที่อยู่นอกโฟลเดอร์เว็บ"

เครื่องมือเปิดต้นฉบับแบบอ่านอย่างเดียว ใช้ SQLite backup API ตรวจ integrity ของสำเนา
และสร้าง SHA-256 manifest ไม่อัปโหลดหรือส่งข้อมูลออกภายนอก ไม่สำรองไฟล์รูปแยกให้อัตโนมัติ
สามารถใช้กับฐานข้อมูลบน Render ได้เมื่อมีช่องทางรันคำสั่งและดาวน์โหลดที่ได้รับอนุญาต

เก็บสำเนานี้เป็นต้นฉบับอ้างอิง ใช้สำเนาอีกชุดสำหรับเปิดทดสอบ เพราะเซิร์ฟเวอร์อาจทำ migration เมื่อเริ่ม

## 4. เตรียมเครื่อง Windows สำหรับทดสอบ

1. ดาวน์โหลดโค้ดเวอร์ชันที่เลือก ติดตั้ง Node.js และรัน npm ci บน Windows
2. ห้ามคัดลอก node_modules จาก Linux/Render เพราะ better-sqlite3 เป็น native module
3. วางฐานข้อมูลสำเนาและข้อมูลจริงนอกโฟลเดอร์โปรแกรม เช่น C:\FactoryExamData
4. กำหนด DATA_DIR ให้ชี้โฟลเดอร์นั้น และกำหนด AUTH_SECRET ผ่านค่าตั้งที่ปลอดภัย
5. ตั้ง PORT แล้วรัน node server.js เพื่อทดสอบในเครื่องก่อน
6. ให้ IT ตั้ง Firewall เฉพาะเครือข่ายที่อนุญาต และทดสอบทั้ง LAN/Wi-Fi

อย่าเก็บฐานข้อมูล ไฟล์สำรอง หรือไฟล์ค่าลับไว้ในโฟลเดอร์โปรแกรม:
ระบบปัจจุบันให้บริการไฟล์จากโฟลเดอร์โปรเจกต์ จึงต้องตรวจการเข้าถึงไฟล์ก่อนเปิดใช้จริง
การติดตั้ง dependencies ครั้งแรกต้องใช้อินเทอร์เน็ตหรือเตรียมแพ็กเกจ Windows ไว้ครบ

## 5. ตรวจรับก่อนเปิดใช้จริง

- [ ] จำนวนพนักงาน ข้อสอบ ผลสอบ และผลประเมินตรงกับสำเนาต้นฉบับ
- [ ] เข้าระบบแต่ละสิทธิ์และตรวจข้อจำกัดการเข้าถึง
- [ ] ทำข้อสอบ บันทึกเกณฑ์ คะแนนดิบ และผลประเมินด้วยข้อมูลทดสอบ
- [ ] รูปข้อสอบแสดงครบและรายงานเปิดได้
- [ ] ตัดอินเทอร์เน็ตภายนอกแต่คง LAN/Wi-Fi แล้วทดสอบทุกหน้าสำคัญ
- [ ] เริ่มระบบอัตโนมัติหลังรีสตาร์ตและปิด Sleep
- [ ] สำรองและกู้คืนสำเร็จบนสำเนาทดสอบ
- [ ] กำหนด HTTPS/ชื่อภายในและความปลอดภัยร่วมกับ IT

## 6. วันย้ายจริง

หยุดการบันทึกบน Render → สำรองล่าสุด → ตรวจสำเนา → นำเข้าที่ Windows
→ ทดสอบ → แจ้งผู้ใช้เปลี่ยน URL ห้ามเปิดสองระบบให้รับคะแนนพร้อมกัน
เก็บ Render และสำเนาก่อนย้ายไว้จนตรวจรับ หากย้อนกลับหลังมีข้อมูลใหม่ต้องวางแผนย้ายข้อมูลกลับก่อน
